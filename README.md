
# DEROX OS 2.0

**Freedom • Performance • Innovation**

An independent Linux distribution built from scratch. This repository hosts the development assets, bootloader themes, and build infrastructure for **DEROX OS 2.0**.

## Features & Components
- **GRUB2 Bootloader Theme**: Black and purple-neon custom boot interface (`grub-theme-derox2`).
- **Independent Architecture**: Built directly around upstream open-source components and the Linux kernel.
- **Open Source**: Licensed under the MIT License.

## Structure
- `grub-theme-derox2/` — Bootloader theme configuration (`theme.txt`) and visual assets.
- `scripts/` — Build automation and root filesystem generation scripts.
